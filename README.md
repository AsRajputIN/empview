# Employee Management App - Flutter Frontend

A modern, feature-rich employee management mobile application built with Flutter. The app displays all employees and highlights those who have been with the organization for more than 5 years and are active.

## ✨ Features

### Core Features
- ✅ **Employee Listing** - Display all employees in a beautiful list view
- ✅ **Smart Highlighting** - Green highlight for veterans (5+ years & active)
- ✅ **Add Employee** - Form with validation to add new employees
- ✅ **Edit Employee** - Update existing employee information
- ✅ **Delete Employee** - Remove employees from the system
- ✅ **Search Employees** - Real-time search by name, email, or position
- ✅ **Filter Employees** - Filter by status (Active/Inactive) and years of service
- ✅ **View Details** - Detailed view of each employee

### Technical Features
- 🏗️ **MVVM Architecture** - Clean separation of concerns
- 🎯 **BLoC Pattern** - Robust state management
- 🌐 **RESTful API Integration** - Seamless backend communication
- 📱 **Responsive Design** - Works on all screen sizes
- ⚡ **Real-time Updates** - Instant UI updates
- 🔒 **Form Validation** - Comprehensive input validation
- 🎨 **Material Design 3** - Modern UI components
